# Working in this repository

## Git identity

Every commit in this repository is authored as the owner's personal account:

```
git config user.name  "Edu Calvo"
git config user.email "educlopez93@gmail.com"
```

Set this before the first commit of a session, whatever email the session or machine reports for the user. Never commit with a work or company address, never add a `Co-authored-by` line for one, and never mention an employer in commits, PRs, code or docs. The `Identity` check on pull requests fails if any commit breaks this.
